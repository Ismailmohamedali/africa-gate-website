# Africa Gate for Engineering Solutions — Website

Static bilingual (Arabic / English) website. No build step needed: upload the files as they are.

## Publish on GitHub Pages
1. Create a new repository on GitHub and upload **all files in this folder** to its root (keep the `assets` folder as is).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<username>.github.io/<repository>/`.

To use a custom domain (e.g. `africagate-eng.com`), add it under **Settings → Pages → Custom domain** and point the domain's DNS to GitHub Pages.
